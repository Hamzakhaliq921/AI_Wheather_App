## 📌 Overview

WeatherNow is a modern, interactive weather application that provides real-time weather data, AI-powered chatbot assistance, and interactive maps. Built with HTML5, CSS3, JavaScript, and Bootstrap 5, this app fetches live weather data from WeatherAPI and integrates OpenRouter AI for intelligent weather conversations.


## 🚀 Features

### Current Weather Data
- 🌡️ Real-time temperature in Celsius
- 📍 Location and country information
- 🌤️ Weather conditions with icons
- 🤔 "Feels like" temperature

### Atmospheric Information
- 💨 Pressure (mb)
- 👁️ Visibility (km)
- ☁️ Cloud cover percentage
- 💧 Dew point temperature

### Wind & Sun Data
- 💨 Wind speed (km/h)
- 🌬️ Gust speed (km/h)
- ☀️ UV Index
- 🌙 Day/Night indicator

### AI Chatbot Assistant
- 🤖 Intelligent weather conversations
- 🍽️ Food recommendations based on weather
- 🗺️ Tourist place suggestions
- 🌡️ Temperature-based clothing advice
- 💬 Real-time responses using OpenRouter AI

### Interactive Maps
- 🗺️ Dynamic Google Maps integration
- 📍 Auto-updates based on searched city
- 🔍 Zoom and pan capabilities

### Additional Features
- 🌓 Dark/Light theme toggle
- 📱 Fully responsive design
- 🇵🇰 Pre-loaded data for 5 Pakistani cities
- 🔍 Search any city worldwide
- 💾 Theme preference saved locally
